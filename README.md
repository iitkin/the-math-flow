# The Math Flow

A landing page for an elementary math tutoring service (Grades K–5), built with React, TypeScript, Vite, and Tailwind CSS v4.

## Features

- Responsive hero with CTA
- Stats bar, how-it-works steps, curriculum grid
- Testimonials, pricing plans
- Contact / booking form with success state
- Smooth-scroll navigation (desktop + mobile hamburger menu)

## Stack

| Tool | Version |
|------|---------|
| React | 19 |
| TypeScript | 5 |
| Vite | 6 |
| Tailwind CSS | 4 |

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build   # type-check + bundle → dist/
npm run preview # preview production build locally
```
